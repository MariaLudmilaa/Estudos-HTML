Este é um projeto prático desenvolvido para consolidar os conceitos fundamentais de HTML5, simulação de navegação entre páginas e estruturação básica de elementos web sem o uso de estilos (CSS) ou rotas dinâmicas.

Sobre o Projeto:
O objetivo do projeto foi recriar a estrutura inicial da interface do Mercado Livre utilizando marcação HTML simples.

O que foi praticado:
*Estruturação de Documentos HTML5: Definição correta do cabeçalho (<head>), metadados e corpo (<body>).
*Navegação Estática: Implementação de links internos (<a>) simulando um menu de navegação (Home, Produtos, Contato).
*Marcação e Imagens: Uso do elemento <figure> acompanhado de <figcaption> para associar legendas descritivas às imagens exibidas na página.
*Hierarquia de Títulos: Aplicação dos níveis de títulos (<h1>, <h2>) para organização da informação.
